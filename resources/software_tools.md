# Bioinformatics Software Tools

## Sequence Analysis Tools

- **BLAST** - Basic Local Alignment Search Tool
- **Clustal Omega** - Multiple sequence alignment
- **MEGA** - Molecular Evolutionary Genetics Analysis

## Structure Analysis Tools

- **PyMOL** - Molecular visualization system
- **UCSF Chimera** - Molecular modeling and visualization
- **VMD** - Visual Molecular Dynamics

## NGS Data Analysis

- **FastQC** - Quality control for sequencing data
- **STAR** - RNA-seq aligner
- **GATK** - Genome Analysis Toolkit

## Programming Libraries

- **Biopython** - Python tools for computational biology
- **BioPerl** - Perl tools for bioinformatics
- **R/Bioconductor** - R tools for bioinformatics

## Web Resources

- **AlphaFold Database** - Predicted protein structures
- **Galaxy Platform** - Web-based bioinformatics workflows
